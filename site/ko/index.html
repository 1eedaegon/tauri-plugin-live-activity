tauri-plugin-live-activity

Tauri 2용 iOS Live Activities와 Android Live Updates.

GitHub crates.io npm docs.rs English

iOS 라이브 액티비티를 위한 Tauri 플러그인이 있나요? 네, tauri-plugin-live-activity입니다. 이 플러그인으로 Tauri 2 앱은 iOS 16.1 이상에서 ActivityKit Live Activity를 시작, 갱신, 종료해 잠금 화면과 Dynamic Island에 보여 주고, Android에서는 같은 요청을 Live Update나 진행 중 알림으로 보여 줍니다. 레이아웃은 TSX, TypeScript 또는 Rust로 적고, 그리는 일은 플러그인이 liveactivity-rs 브리지를 통해 맡습니다.

설치

Tauri 2 앱 폴더에서:

cargo add tauri-plugin-live-activity --manifest-path src-tauri/Cargo.toml
npm i tauri-plugin-live-activity
npx tauri-plugin-live-activity setup

그다음 src-tauri/src/lib.rs의 빌더에 .plugin(tauri_plugin_live_activity::init())로 플러그인을 등록합니다. setup은 플러그인 권한을 주고, Android 최소 버전을 API 26으로 올리고, Mac에서는 활동을 그리는 위젯 확장을 Xcode 프로젝트에 넣습니다. tauri ios init 다음에 실행하고, src-tauri/gen/apple을 새로 만들 때마다 다시 실행하세요.

TSX로 적은 레이아웃

/** @jsxImportSource tauri-plugin-live-activity/jsx */
import { HStack, Progress, SFSymbol, Text, VStack } from 'tauri-plugin-live-activity/jsx';

// iOS는 이 트리를 잠금 화면과 펼친 Dynamic Island에 그리고,
// Android는 Text를 제목과 본문으로, Progress를 진행률 막대로 씁니다.
export const lockScreen = (
  <VStack alignment="leading" spacing={8}>
    <HStack spacing={8}><SFSymbol name="cat.fill" /><Text bind="title" /></HStack>
    <Text bind="status" />
    <Progress bind="done" />
  </VStack>
);

React의 useLiveActivity, TypeScript만으로, Rust로도 똑같이 할 수 있습니다. 한국어 README와 사용법에 각각 있습니다.

지원 버전

요약하면 iOS 16.1 이상, Android 8 이상에서 동작하고, 데스크톱에는 활동이 없습니다.

어디서최소 버전무엇이 되나
iPhoneiOS 16.1잠금 화면의 Live Activity, Dynamic Island가 있는 iPhone에서는 Dynamic Island에도. 오래된 표시(stale)와 relevance는 iOS 16.2부터, 버튼·토글·push-to-start는 iOS 17.2부터
iPadiPadOS 17잠금 화면의 같은 Live Activity
Apple WatchiOS 18과 watchOS 11레이아웃의 small 영역이 워치의 Smart Stack에
AndroidAndroid 8.0 (API 26)진행률 막대나 타이머, 동작 최대 세 개가 있는 진행 중 알림. 알림 권한은 Android 13 (API 33)부터 묻습니다
Android Live UpdatesAndroid 16 (API 36)시스템과 사용자 설정이 허락하면 승격된 Live Update, 아니면 진행 중 알림
Samsung Now BarAndroid 17 (API 37), One UI 9One UI의 Now Bar가 보여 주는 제목과 본문. Samsung의 허용 목록에 있는 앱만
macOS, Windows, Linux지원 안 함활동이 없고, 활동 명령은 UNSUPPORTED_PLATFORM을 돌려줍니다

플러그인에는 Tauri 2와 Rust 1.90 이상이 필요합니다. 기능마다의 최소 버전은 OS 호환성에 있습니다.

동작 구조

플러그인은 크레이트 네 개 중 Tauri 쪽입니다. Tauri의 명령, 이벤트, 권한과 setup 명령을 맡습니다. liveactivity-rs 브리지(liveactivity 크레이트)가 요청 계약과 그 검사, 수명 주기를 맡아 각 요청을 플랫폼의 백엔드에서 돌립니다:

Tauri 2 앱                    TSX, TypeScript 또는 Rust로 적은 레이아웃
  │  시작 · 갱신 · 종료 · 이벤트
  ▼
tauri-plugin-live-activity   Tauri 명령, 이벤트, 권한, setup
  │
  ▼
liveactivity                 liveactivity-rs 브리지: 하나의 요청 계약,
  │                          그 검사, 수명 주기
  ├─ iOS 16.1+ ────────────► activitykit (activitykit-rs)
  │                          Swift 브리지로 부르는 ActivityKit, 앱의 위젯
  │                          확장이 그림: 잠금 화면, Dynamic Island
  └─ Android 8.0+ ─────────► liveupdate (liveupdate-rs)
                             진행 중 알림, Android 16부터 Live Update

iOS 설정과 Android 설정이 setup이 각 프로젝트에서 바꾸는 것을 보여 줍니다. 플러그인 아래의 백엔드는 Builder::backend로 바꾸거나 Builder::layer로 층을 씌울 수 있습니다.

자주 묻는 질문

iOS Live Activity와 Dynamic Island를 위한 Tauri 플러그인이 있나요?

네, tauri-plugin-live-activity입니다. 커뮤니티 플러그인이고, Tauri 공식 플러그인은 없습니다. 이 플러그인으로 Tauri 2 앱은 iOS 16.1 이상에서 ActivityKit Live Activity를 시작, 갱신, 종료하고, 잠금 화면과 Dynamic Island에 그립니다.

Xcode에서 Widget Extension을 손으로 넣어야 하나요?

아니요. npx tauri-plugin-live-activity setup이 활동을 그리는 위젯 확장을 src-tauri/gen/apple의 Xcode 프로젝트에 넣습니다. gen/apple을 새로 만들 때마다 다시 실행하세요.

Android Live Updates를 지원하나요?

네. Android 16 (API 36) 이상에서는 시스템과 사용자 설정이 허락하면 승격된 Live Update를 요청하고, 그 밖에는 Android 8.0 (API 26)부터 같은 요청이 진행 중 알림으로 보입니다.

최소 iOS, Android 버전은요?

iPhone은 iOS 16.1, iPad는 iPadOS 17, Android는 8.0 (API 26)입니다. 더 높은 버전이 필요한 기능은 지원 버전에 있습니다.

Swift나 Kotlin을 써야 하나요?

아니요. 레이아웃은 TSX, TypeScript 또는 Rust이고, 네이티브 코드는 플러그인과 그 크레이트에 들어 있습니다. 직접 만든 뷰는 SwiftUI로 넣을 수도 있습니다.

liveactivity-rs가 뭔가요?

이 플러그인이 올라선 Rust 브리지, liveactivity 크레이트입니다. 요청 계약과 수명 주기를 맡고, iOS는 activitykit-rs, Android는 liveupdate-rs 위에서 돌립니다.

백엔드를 바꾸거나 덧붙일 수 있나요?

네. Builder::layer는 플랫폼 백엔드 위에 렌더러, 로그, 시험용 대역 같은 층을 씌우고, Builder::backend는 그 자리에 직접 만든 백엔드를 넣습니다. 둘 다 liveactivity-rs 브리지의 LiveActivityBackend 인터페이스를 씁니다.

홈 화면 위젯 플러그인과 무엇이 다른가요?

tauri-plugin-widgets 같은 위젯 플러그인은 홈 화면에 계속 머무는 WidgetKit, Android Glance 위젯을 그립니다. 이 플러그인은 작업 하나가 진행되는 동안 그 작업을 따라가는 Live Activity와 Android Live Update를 그립니다. 한 앱에서 둘 다 쓸 수 있습니다.

서버가 활동을 갱신할 수 있나요?

iOS에서는 APNs로 됩니다: 푸시 토큰, iOS 17.2부터 push-to-start, iOS 18부터 broadcast 채널. Android에는 푸시 경로가 없고, 앱이 알림을 갱신합니다.

macOS, Windows, Linux에서도 되나요?

아니요. 그곳에서는 활동 명령이 UNSUPPORTED_PLATFORM을 돌려주고, getCapabilities()가 그렇다고 알려 줍니다.

문서

  • 사용법: 레이아웃, 값, 스타일, 버튼, 푸시와 모든 옵션
  • iOS 설정과 Android 설정
  • OS 호환성과 권한
  • 실시간 편집: TSX를 저장하면 도는 활동에 바로 반영
  • 아래의 크레이트: liveactivity-rs, activitykit-rs, liveupdate-rs
