## Default Permission

Read capabilities, permissions and activities. Mutations require explicit grants.

#### This default permission set includes the following:

- `allow-get-capabilities`
- `allow-check-permissions`
- `allow-list`
- `allow-list-layout`
- `allow-push-tokens`
